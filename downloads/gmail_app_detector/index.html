From package to install

Put MailScope on the Web Store.

Chrome does not allow websites to silently install extensions. The Web Store is the standard public install path.

01 / PACKAGE

Download this ZIP

Use the package above. It contains the extension manifest and required runtime assets at the archive root.

02 / PUBLISH

Upload in Developer Dashboard

Create the store listing, complete its privacy and permission disclosures, then submit it for review.

03 / INSTALL

Share the store listing

After approval, link your website's install button to the listing. Each user confirms with Add to Chrome.

●Before publishing: configure the Google OAuth redirect URI for the published extension ID and review Gmail scopes. The extension requests read and modify access; message removal moves mail to Trash.
