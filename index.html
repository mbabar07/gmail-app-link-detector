Good to know

Frequently asked questions.

Is the extension download included?

Add your actual extension ZIP to the downloads folder using the filename shown by the download button. Do not publish the website until that file is included.

Does this website access my Gmail?

No. This is a static product information website. It does not connect to Gmail or access email data.

Is this an official Chrome Web Store install?

This page provides a developer ZIP download. If the extension is published on the Chrome Web Store, link to its official listing instead.

Can I edit the website?

Yes. The website is plain HTML and CSS in index.html. Edit the text, colors, sections, and logo with any code editor.
