# Gmail App & Link Detector — Website Source

This is a static website. It uses plain HTML/CSS and does not require a paid AI website builder or credits.

## Edit the website
- Open `index.html` in any text/code editor (VS Code is free).
- Change the wording, colors, layout, and links in the HTML/CSS.
- Replace `assets/logo.svg` with your own logo if you want.

## Add your extension ZIP
1. Put your real Chrome extension ZIP in the `downloads` folder.
2. Name it exactly: `Gmail-App-Link-Detector-1.0.0-upload.zip`
3. Keep the filename consistent with the download link in `index.html`.
4. Test the ZIP locally before publishing. The site package does not include the extension ZIP because the actual ZIP was not available to attach during this build.

## Free hosting with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a public repository named `gmail-app-link-detector`.
3. Upload `index.html`, `assets/`, and `downloads/` (including your real ZIP).
4. In repository Settings → Pages, select deploy from the `main` branch and root folder.
5. GitHub will provide a free `github.io` address. You can later connect a custom domain you own.

Note: free hosting can give you a free subdomain, but a custom `.com` domain normally costs money. Keep the extension ZIP in the repository only if you are comfortable making it publicly downloadable.
